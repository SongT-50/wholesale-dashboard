전국 도매시장 법인 대시보드

전국 32개 공영도매시장, 60개+ 법인의 거래 현황을 지도 위에서 한눈에 비교합니다.

이 대시보드는 뭔가요?

농산물 공영도매시장에서는 매일 수천 건의 경매·거래가 이뤄집니다.
이 대시보드는 공공데이터포털(data.go.kr)의 도매시장 거래 데이터를 수집·분석해서,
어떤 법인이 어떤 품목을 얼마에, 어디 산지에서 가져오는지 시각화한 도구입니다.

기본 사용법

📅 날짜 이동
상단 < > 버튼 또는 키보드 ← → 키로 날짜를 변경합니다.
오늘 데이터가 없으면 자동으로 가장 최근 거래일로 이동합니다.

📊 기간 합산
1일 1주 1달 버튼으로 기간을 변경합니다.
1주·1달은 여러 날의 데이터를 합산해서 보여줍니다.

3가지 보기 모드

1. 법인별 (단축키 1) — 법인을 거래 순으로 정렬. 클릭하면 상세 패널이 열리며 품목·산지를 볼 수 있습니다.
2. 시장별 (단축키 2) — 시장 단위로 묶어서 비교. 클릭하면 해당 시장으로 줌인합니다.
3. 가격비교 (단축키 3) — 같은 품목의 법인별 가격을 한눈에 비교합니다. 산지 분포도 함께 표시됩니다.
4. 입하예약 (단축키 4) — 전자송품장에 등록된 확인된 입하예약을 시장/법인별로 확인합니다.

지도 위 기능

원 크기/색상
초록 = 상위 30%
파랑 = 중간
주황 = 하위 40%
원 크기는 선택한 지표에 비례합니다.

지표 전환 (단축키 M)
물량 금액 건수 버튼으로 지도의 기준 지표를 바꿉니다.

물류 흐름 (단축키 F)
산지→시장 물류 아크를 지도에 표시합니다.

법인 상세 패널

법인을 클릭하면 우측에 상세 패널이 열립니다.
품목 클릭 → 해당 품목의 산지가 지도에 표시됩니다 (주황=우리 산지, 보라=경쟁 산지).
"우리 5개 / 미거래 7개" — 우리 법인이 거래하는 산지 vs 다른 법인만 거래하는 산지를 비교합니다.
Esc 키로 닫을 수 있습니다.
