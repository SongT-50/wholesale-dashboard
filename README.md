# 전국 도매시장 물류흐름 대시보드

전국 32개 공영도매시장 83개 법인·공판장으로 들어오는 농산물이 어느 산지에서 얼마나 오는지 지도로 보여줍니다.
매일 자동으로 갱신됩니다.

👉 바로 보기: https://songt-50.github.io/wholesale-dashboard/

## 공개 범위
- 이 사이트에는 **최근 3개월(90일)** 의 일별 자료만 올려 둡니다(저장 공간 때문). 그래서 공개판에서는 「1년」·「전체」 버튼이 보이지 않습니다.
- 2018년 1월부터의 일별 자료가 필요하시면 이 저장소의 **[Issues](https://github.com/SongT-50/wholesale-dashboard/issues)** 에 남겨 주세요.

## 데이터 출처
- 한국농수산식품유통공사(aT) 도매시장 정산 공공데이터
- KAMIS 농산물 유통정보(가격 비교)
- 기상청 자료

가공한 자료는 각 제공기관의 이용 조건을 따릅니다.

## 직접 실행해 보기
정적 HTML 입니다. 브라우저가 `file://` 로 연 파일에서는 데이터(JSON) 읽기를 막으므로, 저장소 폴더에서 `python -m http.server 8000` 을 띄운 뒤 http://localhost:8000 으로 여세요. 데이터를 만드는 스크립트는 `preprocess.py` 입니다.

## 방문 통계
방문 수 파악을 위해 Google Analytics 를 사용합니다.
